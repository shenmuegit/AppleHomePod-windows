# AppleHome 0.2.0 Preview 1

这是限定设备范围的预发布。当前已验证：**Windows 10 Pro 22H2（19045，x64）与单只 HomePod mini 27.0（AudioAccessory5,1）**。Windows 11、其他型号或固件、立体声对与 Apple TV 分组尚未取得实机资格；向导当前只开放上述单只 mini 档案。

## 下载与安装

下载附件 **`AppleHome-0.2.0-567533684ccd.zip`**，解压并打开 `AppleHome.exe`，无需另装 .NET 或 Rust。

1. HomePod 先在 Apple“家庭”App 初始化，并与电脑连接同一局域网。
2. 按向导安装音频驱动，Windows 要求管理员许可或重启时按提示完成；重启后重新打开应用。
3. 等待自动连接并确认是否听到声音，需要时点击“再播放一次”。名称、Windows 输出与缓冲参数由程序配置。

日常只用 Windows 输出选择、音量和静音控件。完整步骤与已有预览安装的维护方式见附件 `INSTALL.zh-CN.md` 或[安装指南](https://github.com/shenmuegit/AppleHome/blob/main/docs/first-run.md)。

## 本包验证结果

- 在已有合格驱动与设备记录上更新后台，实际采集、连接与首包状态有效。
- 使用正常音乐与 Windows 原生控件确认声音连续、调低/恢复音量正常，静音至少 15 秒后取消静音正常。
- 806 项 .NET 测试、125 项 Python 测试、Ruff、自包含发布与本机启动/引擎握手检查通过。
- 本轮未播放生成音频、录音或做断网测试；采集到发送 p95 约 28–34 ms，不是端到端声学延迟。

**尚未验证：**本包的全新自动驱动安装与重启完整流程、30 分钟或过夜运行、持续视频同步、断网恢复及跨账户运行。同一设备的早期构建有 30 分钟音乐和约 5 分钟视频主观同步记录，不能作为本包重跑结果。其他限制见[兼容矩阵](https://github.com/shenmuegit/AppleHome/blob/main/docs/COMPATIBILITY.md)。EXE 当前未签名，没有自动更新渠道。
